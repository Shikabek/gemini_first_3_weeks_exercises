## 🚀 Задача 1: Семантическая разметка и Медиа (HTML Basics)

**Цель:** Создать структуру главной страницы блога об освоении космоса, используя правильные семантические теги и встраивая медиафайлы. 

**Файл для работы:** `index.html`

**Требования:**
1. Создай стандартную структуру HTML5 документа (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
2. Используй семантический тег `<header>` для шапки сайта. Внутри добавь главный заголовок `<h1>` ("Космический Блог") и навигацию `<nav>` с тремя ссылками (`<a>`): "Главная", "Статьи", "Контакты".
3. Основной контент оберни в тег `<main>`.
4. Внутри `<main>` создай тег `<article>` — это будет твоя первая статья.
5. В статье должны быть:
   - Заголовок статьи `<h2>`.
   - Несколько абзацев текста `<p>`.
   - Изображение `<img>` (найди любое фото космоса в интернете), обязательно добавь атрибут `alt` для доступности (Accessibility).
   - Видеоролик (используй тег `<video>` или встрой с YouTube через `<iframe>`).
6. Добавь подвал сайта, используя тег `<footer>`, с текстом о защите авторских прав (например, `&copy; 2026 Space Blog`).

## 📝 Задача 2: Формы, Доступность и Таблицы (HTML Forms & Tabular Data)

**Цель:** Создать страницу регистрации на экспедицию, используя элементы форм, связав их с `label` для доступности, а также вывести небольшую таблицу расписания.

**Файл для работы:** `registration.html` (создай ссылку на него в навигации из Задачи 1)

**Требования:**
1. Добавь таблицу `<table>` (Расписание запусков). В ней должны быть заголовки `<th>` (Дата, Ракета, Миссия) и хотя бы две строки с данными `<tr>` -> `<td>`.
2. Создай форму `<form>` для записи в экипаж.
3. Форма должна содержать:
   - Текстовое поле для имени (`<input type="text">`).
   - Поле для email (`<input type="email">`).
   - Выбор роли на корабле (Капитан, Инженер, Биолог) через радио-кнопки (`<input type="radio">`).
   - Чекбокс согласия с условиями (`<input type="checkbox">`).
4. **Критически важно (Accessibility):** Каждое поле ввода должно быть жестко связано с тегом `<label>` через атрибуты `id` и `for`.
5. Кнопку для отправки формы (`<button type="submit">`).

## 🎨 Задача 3: Базовая стилизация (CSS Selectors)

**Цель:** Подключить CSS и стилизовать созданные HTML-страницы, используя изученные селекторы.

**Файл для работы:** `style.css` (не забудь подключить его в `<head>` твоих HTML файлов через `<link>`)

**Требования:**
1. **Базовые селекторы:** Измени шрифт для всего документа (тег `body`) на `sans-serif` и задай базовый цвет текста.
2. **Классы и ID:** Добавь класс `.nav-link` ко всем ссылкам в меню и убери у них нижнее подчеркивание (`text-decoration: none`). Добавь уникальный ID `#main-title` к заголовку `<h1>` и поменяй его цвет.
3. **Комбинаторы:** 
   - Сделай так, чтобы *только* абзацы `<p>`, которые находятся *непосредственно* внутри `<article>` (direct child `>`), имели увеличенный межстрочный интервал (`line-height`).
   - Найди первый `<input>` внутри формы и добавь ему рамку (`border`), используя селектор потомка (пробел).
4. **Состояния:** Сделай так, чтобы при наведении курсора (`:hover`) на кнопку отправки формы, у неё менялся цвет фона (`background-color`).
